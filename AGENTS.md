# AGENTS.md

Рабочий контекст для Codex и других агентных CLI при работе с этим репозиторием.

## Проект

Статический Telegram Mini App веб-студии YankSWeb. Связан с основным ботом из `C:/Users/Admin/Desktop/Работа/Проекты/tests`, но хранится в отдельном репозитории.

## Инфраструктура

- Продакшн URL - `https://bot.yanksweb.ru/app/`
- API и админка обслуживаются соседним бот-проектом
- Деплой Mini App идёт отдельно от кода бота
- Канонический локальный репозиторий Mini App - этот репозиторий `C:/Users/Admin/Desktop/Работа/Проекты/yanksweb-tg-bot`
- На VPS live-checkout Mini App находится в `/opt/bot/miniapp/`
- Чувствительные доступы и вспомогательные reference-заметки сохранены только в локальном архиве: `C:/Users/Admin/.codex/claude-import/projects/c--Users-Admin-Desktop----------------boli-net/memory/`

## Структура

- `index.html` - основная оболочка Mini App
- `style.css` - стили
- `app.js` - клиентская логика
- `data.js` / `data-live.js` - данные и синхронизация контента
- `lucide.js` - текущий набор иконок

## Связь с основным ботом

- Этот репозиторий отвечает за фронтенд Mini App.
- Данные и часть контента приходят из основного bot/api-проекта.
- Если задача затрагивает API, JWT, админку, лиды, CMS или регенерацию `data-live.js`, сначала проверять соседний репозиторий `tests`.
- Папка `tests/miniapp/` в соседнем бот-репозитории - только интеграционный снапшот. Не использовать её как source of truth для продового фронтенда.

## Workflow

- Все статические правки Mini App делать здесь: `index.html`, `style.css`, `app.js`, `data.js`, `lucide.js`, `favicon.svg`
- После завершения правок по умолчанию: `git add` -> `git commit` на русском -> `git push`
- Деплой статического Mini App на VPS:

```bash
ssh -i ~/.ssh/vps_yanksweb root@94.198.217.56 "cd /opt/bot/miniapp && git pull origin main"
```

- `data-live.js` на VPS может меняться отдельно от этого репозитория, потому что его регенерирует API из соседнего бот-проекта
- Если менялась только CMS/контентная часть через админку, проверять именно `data-live.js`, а не ожидать изменений в `app.js`/`index.html`/`style.css`

## Мигрированная память из .claude

- Визуальный ориентир для Mini App - не цвета, а стиль UltimaVPN: чёткие карточки, выраженная иерархия, аккуратные контейнеры под иконки, читаемое разделение секций.
- Не использовать Lucide для нового визуального слоя, если нет жёсткой причины. Для новых решений предпочитать другие наборы иконок или собственные SVG.
- Коммиты в этом проекте писать на русском языке.
- Полный raw-архив старой проектной памяти сохранён локально и не зависит от состояния `.claude`.
